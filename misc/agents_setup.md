# Как да приложите AGENTS.md към Вашия AI агент

Файлът [`AGENTS.md`](AGENTS.md) казва на AI инструментите как да се държат по време на курса (вижте [AI политиката](../ai_policy.md)). Различните инструменти го зареждат по различен начин. Този документ показва как да го настроите за Claude Code, Codex и GitHub Copilot.

> `AGENTS.md` е **инструкция**, а не заключване. Агентът може да я пренебрегне. Затова за всеки инструмент по-долу има и настройка за **режим само за четене**, който политиката изисква. Използвайте и двете.

## Общо: къде да сложите файла

Копирайте `AGENTS.md` в **корена на проекта си** (папката, която отваряте в инструмента, обикновено където е `.git`):

```
my-homework/
├── AGENTS.md      <- тук
├── src/
└── ...
```

Файлът трябва да се казва точно `AGENTS.md`. Не го променяйте — политиката изисква агентът да не го редактира, а и не бива да отслабвате правилата.

## Claude Code

Актуалните версии на Claude Code (v2.1.277 и по-нови) **четат `AGENTS.md` директно**, но само ако в проекта (или в папка над него) **няма** `CLAUDE.md` или `CLAUDE.local.md`. Ако има такъв, Claude чете само него.

Затова:

- Няма `CLAUDE.md` и версията е достатъчно нова → нищо допълнително не е нужно.
- Имате `CLAUDE.md`, или версията е по-стара → създайте/допълнете `CLAUDE.md` с ред:

  ```
  @AGENTS.md
  ```

  (Символична връзка `ln -s AGENTS.md CLAUDE.md` също работи, но не е удачна на Windows.)

**Режим само за четене.** Plan режимът чете файлове, но не редактира. Стартирайте с:

```bash
claude --permission-mode plan
```

или го задайте постоянно в `.claude/settings.json`. Там можете и изрично да премахнете инструментите за промяна и изпълнение:

```json
{
  "permissions": {
    "defaultMode": "plan",
    "deny": ["Edit", "Write", "NotebookEdit", "Bash"]
  }
}
```

Правилата в `permissions` се налагат от самия Claude Code, а не от модела — за разлика от `AGENTS.md`.

Проверка: в сесията напишете `/memory` и потърсете пътя до `AGENTS.md` (или до `CLAUDE.md`) в списъка.

## Codex (OpenAI)

Codex **чете `AGENTS.md` автоматично** — от корена на git репото надолу до текущата папка. Не е нужна настройка.

**Режим само за четене:**

```bash
codex --sandbox read-only --ask-for-approval on-request
```

Проверка:

```bash
codex --ask-for-approval never "Summarize the current instructions."
```

Отговорът трябва да отразява съдържанието на `AGENTS.md`.

## GitHub Copilot (VS Code)

Поддръжката на `AGENTS.md` във VS Code е **изключена по подразбиране**. Включете я:

1. `Settings` → потърсете `chat.useAgentsMdFile` → отметнете.
2. Ако имате и `.github/copilot-instructions.md`, изтрийте го или се уверете, че не противоречи на `AGENTS.md`.

**Режим само за четене:** в чата изберете агент **Ask** (отговаря на въпроси, без да пипа кода) или **Plan** (пише план, без да променя код). **Не** използвайте **Agent** — той редактира файлове и изпълнява команди в терминала.

**Изключете и inline допълненията** — те пишат код вместо Вас, а `AGENTS.md` не ги контролира. В `.vscode/settings.json` на проекта:

```json
{
  "github.copilot.enable": { "*": false }
}
```

Проверка: в Ask режим напишете „Fix my function“ — Copilot трябва да откаже и да Ви насочи с въпроси.

## Други инструменти

Cursor и OpenCode също четат `AGENTS.md` от корена на проекта. Ако инструментът Ви не го чете, поставете съдържанието му във файла му с инструкции.

## Не забравяйте

Ако използвате AI при заданието, всяко предаване трябва да съдържа `AI_USAGE.md`, написан от Вас — вижте [политиката](../ai_policy.md#описване-на-използването-на-ai).
